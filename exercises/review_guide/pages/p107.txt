П1.3. Общи изисквания и организация на файловете 
Използва се 64-битов Python 3.11 или по-нов. Препоръчва се 
отделна виртуална среда. За работа с трите програми са нужни NumPy, 
pandas, SciPy, Matplotlib, scikit-learn, SoundFile, PyAV и xlrd, описани в 
общия файл със зависимости. Не са необходими Word, Excel или python-
docx.

В метаданните и подпапките на набора се запазват оригиналните 
имена. Не се преименуват задания или състояния, за да се замества 
липсващо измерване. Командите по-долу се изпълняват от основната 
папка на разархивирания пакет. Пътят C:/work/DCData_mendeley се 
заменя с действителния път; при интервали се запазват кавичките. На 
Linux/macOS при нужда се използва python3. 
python -m pip install -r requirements_all.txt 
python lab8/lab8_ml.py --help 
python lab9/plot_lab_current.py --help 
python lab10/lab10_vibroacoustics.py --help 
Общият файл инсталира зависимостите за трите упражнения. 
 
Всяка команда се стартира след успешна инсталация на 
зависимостите. Пълните параметри се извеждат чрез --help.
